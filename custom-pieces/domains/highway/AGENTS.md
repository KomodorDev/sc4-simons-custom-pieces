## 1. Domain workflow

Apply the parent [library instructions](../../AGENTS.md) and continue the selected shared workflow; these domain additions do not require restarting workflow selection. Consult the [domain README](README.md) for placement and menu guidance when those features are implemented.

No highway game piece or build adapter is implemented. The [network specification](NETWORK_SPEC.md) records measured native donors and the explicitly provisional diagonal diamond geometry prototype. Establish actual network, width, traffic side, height, and complete donor contracts before registering game pieces; do not infer RHW compatibility from a ramp-shaped train preview or a schematic. Use that specification for highway engineering facts. Shared artwork and document procedures live in [documentation generation](../../docs/WORKFLOW_DOCUMENTATION_GENERATION.md). New subjects and guides deliberately migrated to the split layout use README plus TESTING; a piece has three README chapters and the shared six TESTING chapters. Preserve legacy combined guides until deliberately migrated, and record human observations through the [shared testing guide](../../docs/TESTING.md).
