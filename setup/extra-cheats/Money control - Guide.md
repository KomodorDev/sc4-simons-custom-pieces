# SimCity 4 — change your money balance

**Installed 11 September 2026.** Both DLL files and their required placement were verified. All 133 previous package records and all 431 region files are unchanged. The money command still needs its first in-game check.

## Use the money command after installation

1. Open **SimCity 4 Windows** from your desktop.
2. Open the city whose balance you want to change.
3. Hold **Control** and press **X**. This opens the cheat-entry box. Use Control rather than Command in this Windows edition.
4. Type `moolah 100000000` exactly: one space after moolah, no commas or spaces inside the number.
5. Press **Return**. The current city's total balance becomes **100 million Simoleons**, the game's currency.
6. To retain the new balance, press **Control + S** and wait for saving to finish.

| Desired balance | Type |
|---|---|
| 1 million | `moolah 1000000` |
| 10 million | `moolah 10000000` |
| 100 million | `moolah 100000000` |

The command replaces the current balance. It does not add the number to the existing balance. Normal spending and income continue afterwards. Repeat the command whenever you want to change your money again. This affects the city currently open; other cities keep their balances.

If the command remains in the box and nothing happens, press Escape, quit the game, and launch **SimCity 4 Windows** again. The original Extra Cheats file must be loaded when the game starts. The separate native Mac game does not use these Windows plugins.

## Installed package

The installed sc4pac package is `simmaster07:extra-cheats-dll` version **1.1.1-3**. It includes the original **SimCity 4 Extra Cheats Plugin.dll**, which enables the money command, and **ExtraExtraCheats.dll**, which adds other commands. sc4pac places links to both directly inside your Windows Plugins folder; keep those links.
